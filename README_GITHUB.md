# Eyad Planner

تطبيق شخصي بسيط لتنظيم المهام والدروس مع Pomodoro ووضع داكن وصورة جدول المدرسة.

## بناء APK على GitHub

1. ارفع ملفات المشروع إلى مستودع GitHub.
2. ادفع الملفات إلى فرع `main` أو `master`.
3. افتح تبويب **Actions**.
4. اختر **Build Eyad Planner APK**.
5. بعد انتهاء العملية افتح الـworkflow الناجح.
6. من قسم **Artifacts** حمّل **EyadPlanner-APK**.
7. فك الضغط عن الـArtifact وستجد `app-debug.apk` جاهزًا للتثبيت على Android.

يمكنك أيضًا تشغيل البناء يدويًا من **Actions → Build Eyad Planner APK → Run workflow**.
